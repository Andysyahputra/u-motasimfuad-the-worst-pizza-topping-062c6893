An entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893) "The Worst Pizza Topping" bounty. `main.ts` (Node 22, standard library only) writes one line — a pitch for a terrible pizza topping — to `/output/entry.txt`:

> Introducing our new topping: yesterday's socks, lightly toasted, with a drizzle of regret and a sprinkle of 'why did we do this'.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
